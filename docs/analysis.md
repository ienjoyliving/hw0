# Исходный процедурный код (только для чтения и анализа)

import random

def play_guess_number_procedural():
    secret = random.randint(1, 100)
    attempts = 0
    max_attempts = 10
    print("Я загадал число от 1 до 100. У вас 10 попыток.")
    while attempts < max_attempts:
        try:
            guess = int(input("Ваш вариант: "))
        except ValueError:
            print("Введите число!")
            continue
        attempts += 1
        if guess < secret:
            print("Больше!")
        elif guess > secret:
            print("Меньше!")
        else:
            print(f"Угадали! Попыток: {attempts}")
            return
    print(f"Попытки закончились. Было загадано: {secret}")

print("Функция определена, готова к анализу")

## 1.2. Ответы на вопросы

### 1. Какие классы вы выделите? Обоснуйте.

Я выделю классы: **Game()**, **Player()**, **UI()**.

| Класс | Ответственность |
|---|---|
| **Game()** | Хранит состояние игры (загаданное число, лимит) и управляет логикой проверки |
| **Player()** | Хранит данные игрока (счетчик попыток) и отвечает за ввод/валидацию |
| **UI()** | Отвечает за вывод сообщений и получение сырого ввода |

### 2. Какие атрибуты будут приватными?

- `self.__secret` — чтобы нельзя было подсмотреть загаданное число извне.
- `self.__max_attempts` — чтобы нельзя было изменить лимит попыток в процессе игры.
- `self.__attempts` — чтобы нельзя было накрутить или сбросить количество попыток вручную.

### 3. Какие методы будут публичными?

- `game.run()` — чтобы игру можно было запустить.
- `game.check_guess(guess)` — чтобы проверить введенное число и вернуть результат (больше/меньше/угадал).
- `player.make_guess()` — чтобы получить и валидировать выбор игрока.
- `ui.show_message()` — для вывода текста.
- `ui.get_input()` — для получения ввода от пользователя.

### 4. Есть ли в исходном коде «God Object»?

**Да, есть.** Это функция `play_guess_number_procedural()`. В ней сосредоточена абсолютно вся логика. Она генерирует случайное число, обрабатывает ввод, валидирует данные, сравнивает числа, управляет циклом игры и выводит результаты.
